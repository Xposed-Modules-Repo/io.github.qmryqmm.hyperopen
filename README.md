# HyperOpen

**HyperOpen** 是一款专为 **小米澎湃 OS（Xiaomi HyperOS）** 打造的屏下指纹快捷方式（FOD QuickOpen）深度增强 Xposed / LSPosed 模块。

本模块通过接管并重构系统界面（`com.android.systemui`）中的指纹长按快捷面板，将系统原生单调的扇形有限快捷方式升级为**圆形蜂窝阵列视界**，带来兼具澎湃光学质感、丝滑鱼眼交互与极高自由度的指纹快捷启动体验。

---

## ✨ 核心特性

### 1. 圆形蜂窝布局与物理鱼眼交互
- **蜂窝阵列排布**：打破原生数量限制，支持多个快捷项目以中心对称的圆形蜂窝结构紧密排布。
- **动态鱼眼缩放**：手指在指纹区域滑动时，焦点图标与邻近气泡具备基于距离影响半径的连续鱼眼放大、透明度过渡与 Z 轴自动置顶防遮挡效果。
- **可视化拖拽排序**：在「快捷项目」管理页内嵌整体蜂窝预览，支持长按图标直接拖拽调整排布顺序并实时磁吸保存。

### 2. 双光学材质与多维高斯模糊渲染
- **双材质引擎**：
  - **高斯模糊材质**：实时局部毛玻璃模糊渲染，通透还原背景色彩层次。
  - **柔光玻璃材质（液态玻璃）**：具备次表面立体散射、菲涅尔动态梯度描边与选中激活外发光辉光动效。
- **全方位参数可调**：
  - 唤醒时全屏模糊遮罩透明度调节；
  - 圆形视界区域直径、垂直偏移量（Offset Y）、底衬开关与独立高斯模糊半径；
  - 气泡图标尺寸、紧凑度间距、内部留白比例及留白区域独立高斯模糊半径；
  - 鱼眼最大放大倍率、影响半径、选中图标内部缩放倍率及顶部提示胶囊背景开关。

### 3. 指纹解锁进入等待时间可调（Hook 系统界面底层）
- **等待阈值可调节**：通过 Hook `MiuiGxzwManager#dismissGxzwView` 中调度系统快捷面板的
  `Handler.postDelayed(mShowRunnable, …)` 延迟，将「指纹解锁后需按住传感器多久才唤出面板」做成可调项（0 ~ 2000 ms）。
- **滑块 500 ms 即系统默认**：500 ms 位置不干预系统原生判定（普通场景 500 ms / 无障碍 TalkBack 下 1000 ms），滑块默认即停在该位置；`0 ms` 为解锁后立即弹出，其余数值强制覆盖系统延迟。
- **精准识别展开任务**：系统 `MiuiGxzwQuickOpenView$1` 被 R8 复用为多个 Runnable，模块在构造时给真正的展开 Runnable 打上附加字段标记，仅拦截该实例，不影响 `fod_auth_fingerprint` 写入等其他逻辑。

### 4. 高度自由的快捷方式与动作预设
- **多类型动作支持**：支持启动任意已安装应用（支持系统应用 / 用户应用分类筛选与搜索）、自定义 Activity 组件、Intent URI 跳转及自定义动作。
- **高频官方动作预设**：内置十余项常用快捷动作一键填入（微信扫一扫、微信付款码、微信收款码、支付宝扫一扫、支付宝付款码、支付宝收钱码、支付宝乘车码、系统相机、手电筒等）。
- **Root 安全兜底唤醒**：针对受限页面提供 Root `am start` 兜底拉起机制，并支持在快捷方式编辑页点击 **「立即启动测试」** 即时验证动作有效性。

### 5. 双矢量图标库（Miuix 125 + Remix 129）
- **Miuix 官方图标库**：内置 125 款 Miuix 风格矢量图标，支持 **5 档线条粗细**（Light / Normal / Regular / Medium / Demibold）自由切换。
- **Remix 图标库**：内置 129 款 Remix Icon 矢量图标（24×24 原生 PathData），覆盖支付、交通、设备、媒体、系统等常用场景。
- **默认快捷项全量使用矢量库**：内置默认快捷项目（微信扫一扫/付款码/收款码、支付宝扫一扫/付款码/收款码、乘车码、手电筒、街拍相机）图标全部采用 Remix 矢量图标，**不再手绘 Path**，跨 SystemUI 与 App 进程一致渲染。
- **多样化图标底垫**：矢量图标支持启用圆形底垫，提供 **实心彩底 + 白色图标**、**微透磨砂底**、**反色微透底 + 彩色图标** 三种质感模式及自定义色盘。
- **单快捷方式独立裁切**：应用图标支持按单个快捷方式独立选择 **抗锯齿圆形裁切** 或 **自适应外扩满铺** 方案。

### 6. 1:1 实时真机壁纸预览
- 支持实时加载系统当前桌面壁纸作为背景，在模块内提供与真实指纹唤醒界面完全一致的全屏交互预览，所有滑块与开关均支持热重载即时预览。

### 7. SystemUI 崩溃安全模式（SafetyGuard 守护）
- **运行期崩溃哨兵**：内置跨进程健康监测与异常拦截机制。若模块 Hook 引发 `SystemUI` 在 5 分钟内连续异常崩溃达到阈值（2 次），将在运行期**即时拆解全部 Hook** 并自动切入安全模式，使系统界面立即恢复原生指纹功能，杜绝卡锁屏或无限重启。
- **可视化状态管理**：支持在设置页查看健康状态与崩溃日志、手动切换 Hook 总开关、一键退出安全模式及清零崩溃记录。

### 8. 一键恢复默认参数（二次确认）
- 在「软件设置」页提供 **「恢复默认参数」** 入口，可一键将全部外观 / 物理 / 震动 / 等待时间参数与快捷项目列表重置为出厂默认值。
- 恢复前弹出**二次确认弹窗**（完整跟随系统深浅色主题），确认后才执行重置并立即持久化生效。

### 9. 原生澎湃风格 UI
- 模块配置界面基于 **Miuix Compose 0.9.4** 构建，支持跟随系统 / 浅色 / 深色模式、**Monet 动态取色** 以及 **胶囊悬浮底栏**。

## 📦 环境要求与安装使用

### 环境要求
- **系统版本**：小米澎湃 OS（Xiaomi HyperOS，Android 10 / API 29 及以上），设备需支持屏下指纹并已在系统设置中开启指纹快捷功能。
- **框架环境**：已安装 **LSPosed**（推荐）或其他兼容 Xposed API 82+ 的框架。
- **可选权限**：
  - **Root 权限**：用于设置页「重启系统界面」一键生效，以及部分受限快捷方式（如微信深层页面）的 `am start` 兜底唤醒。
  - **存储读取权限**：用于在应用内实时预览页加载当前系统真实桌面壁纸。

### 使用步骤
1. 前往 [Releases](https://github.com/qmryqmm/HyperOpen/releases) 页面下载最新版本的 APK 并安装。
2. 打开 **LSPosed 管理器**，启用 **HyperOpen** 模块，并勾选作用域：**系统界面 (`com.android.systemui`)**。
3. 打开 **HyperOpen** 应用，根据喜好调整视觉参数与快捷方式列表。
4. 在模块「设置」页点击 **「重启系统界面」**（或通过 LSPosed 重启 SystemUI 作用域）完成首次挂载。
5. 使用指纹解锁手机时，**保持手指按压在指纹传感器区域**即可唤出 HyperOpen 快捷面板，滑动至目标图标松手即可触发。
   > 💡 **提示**：首次挂载生效后，日常修改快捷方式或调整外观参数均通过跨进程 Provider 与广播**实时热生效**，无需再次重启系统界面。
